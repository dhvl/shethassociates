SHETH ASSOCIATES — PREMIUM WEBSITE V2
=====================================

UPLOAD
------
Upload all files/folders in this package into public_html (or your hosting web root). index.html must be directly inside the web root.

SERVER
------
The front-end is pure HTML/CSS/JS. The enquiry form uses a small PHP endpoint (contact-handler.php) for cPanel/Apache/PHP hosting. If your host does not support PHP, replace the form action with your preferred secure form provider.

PRODUCTION CHECKLIST
--------------------
1. Verify all advocate names, qualifications, enrolment information and practice areas before publication.
2. Replace initials with approved professional photographs when available.
3. Configure SMTP and SPF/DKIM/DMARC for reliable form delivery.
4. Confirm office contact details.
5. Review disclaimer/privacy language with the firm.
6. Update sitemap domain if the live domain differs.
7. Connect Google Search Console / Analytics only after reviewing privacy requirements.

This package intentionally does not invent case results, client names, awards or enrolment numbers.
